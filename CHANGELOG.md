# Changelog

## 1.1.0

- Adds MCP 2026-07-28 stateless transport and discovery support.
- Retains compatibility with MCP 2025-11-25 and 2024-11-05.
- Uses the canonical OAuth issuer (`iss`) defined by RFC 9207.
- Applies a CIMD-first client registration policy while remaining compatible with DCR.
- Distributed as source only; this release is not published to npm.
